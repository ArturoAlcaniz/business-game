# Proyecto Empresarial Multijugador

Este es un proyecto de una aplicación web empresarial multijugador desarrollada con Next.js (frontend) y NestJS (backend).

## Requisitos

- Docker
- Docker Compose

## Instalación

1. Clona el repositorio.
2. Ejecuta `docker-compose up --build` para construir y levantar los contenedores.

## Estructura del Proyecto

- **backend**: Contiene el código del servidor NestJS.
- **frontend**: Contiene el código del cliente Next.js.
